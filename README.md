# Portfolio — Guillaume Imary

Site perso construit avec [Astro](https://astro.build), 100 % statique.

## Développement

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # génère dist/
npm run preview
```

## Contenu

Tout le texte modifiable (services, projets, à propos, liens) est dans `src/data/site.ts`.
Les placeholders à remplacer : `[VOTRE-EMAIL]`, `[Projet X]`, `[CAPTURE DU PROJET]`, liens `#`.

## Déploiement

Vercel détecte Astro automatiquement : importer le dépôt GitHub, aucune configuration nécessaire.
